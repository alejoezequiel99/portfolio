## ✨ Características del Portfolio

- **💻 Blueprint Interactivo con Laptop Central:** Hub de interacción en el Hero que conecta visualmente cada sección con mapas de calor y botones iluminados al pasar el cursor.
- **🎨 Estética Neumorphism Violet:** Paleta corporativa violeta profunda (`#1E0664`, `#4F20D2`, `#7C4DFF`, `#A78BFA`) con sombras táctiles suaves y contrastes de alta fidelidad.
- **📄 Visor & Descargador de CV Integrado:** Modal emergente optimizado para previsualizar e imprimir/descargar el Currículum Vitae en PDF.
- **⚡ Rendimiento de Alto Impacto:** Desarrollado sobre React 18 y Vite, garantizando tiempos de carga ultrarrápidos y transiciones fluidas con Framer Motion.
- **📱 100% Responsivo:** Adaptación precisa para dispositivos móviles, tablets y pantallas de escritorio.

## 🚀 Cómo Ejecutar el Proyecto Localmente

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/alejoezequiel99/portfolio.git
   cd portfolio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173/](http://localhost:5173/) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
